# 工作台素材来源

工作台为自制工具，下列素材随仓库提供：

| 路径 | 内容 | 来源 |
| --- | --- | --- |
| `index.html` | 工作台界面 | 自制 |
| `palettes.json` | 各组配色 | 从本组插画取色（自制） |
| `stickers/<组>/` | 线稿贴纸 | 依本组 MV 画面与 pixiv 插画描摹提取（自制） |
| `stickers/shared/` | 邮戳、通用贴纸 | 自制 |
| `tasks/` | 提交给工作台的截图与蒙版 | 截图取自本组 MV 画面与插画，版权同各组 `SOURCES.md` |
| `autosave/` | 画布状态 | 自制 |

`out/` 为工作台导出记录，不随仓库提供；各组成品见 `postcards/<组>/fg/`。
